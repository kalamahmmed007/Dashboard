# 🧑‍💻 Portfolio Admin Panel (React + Vite)

A modern **Admin Dashboard** to manage a personal portfolio website.  
From here you can control **projects, skills, experience, messages, and settings** — all in one place.

Built with ⚡ **React, Vite, Tailwind CSS, Redux Toolkit**.

---

## ✨ Features

- 🔐 Admin Authentication (Protected Routes)
- 📊 Dashboard with stats
- 📁 Projects CRUD (Add / Edit / Delete)
- 🧠 Skills Management
- 🕒 Experience Manager (auto year calculation supported)
- 💬 Messages from Contact Form
- ⚙️ Admin Settings
- 📱 Fully Responsive UI
- 🚀 Fast build with Vite# Dashboard
